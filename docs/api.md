# API reference

Everything below is importable from `deslop`. Lower-level modules (`deslop.voice.update`,
`deslop.voice.diff`, `deslop.voice.validate`, `deslop.voice.export`, `deslop.blind`,
`deslop.providers.base`) are stable too but documented in their docstrings.

::: deslop
    options:
      members:
        - Corpus
        - Voice
        - Report
        - convert
        - ConvertResult
        - load_brief
        - Brief
        - DraftResult

::: deslop.score.score
    options:
      heading_level: 2

::: deslop.draft.draft
    options:
      heading_level: 2
